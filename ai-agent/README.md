# ESCA HSE AI Agent & Automation Service


A FastAPI-powered AI agent service for Health, Safety & Environment (HSE) management. 
This system uses Groq's LLM with 8 specialized database tools to analyze incidents, 
track CAPAs, monitor KPIs, and provide intelligent insights across 60+ database tables.

## Features
- **Groq LLM Integration** - Efficient token usage with 85% reduction
- **8 Core Database Tools** - Query incidents, CAPAs, employees, KPIs, sensors, and more
- **60+ HSE Tables** - Comprehensive incident and compliance data
- **Multi-language Support** - English & Arabic responses
- **Web UI** - Interactive chat interface for HSE queries
- **Optimized Performance** - <5 seconds average response time

## Stack
- **Backend**: FastAPI + Python
- **AI/LLM**: Groq
- **Database**: MySQL
- **Frontend**: Interactive Web UI
